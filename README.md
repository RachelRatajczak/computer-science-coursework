# Computer Science Coursework

A curated collection of foundational software engineering, systems programming, and computer science academic projects completed during my M.S. in Computer Science. This repository highlights object-oriented programming, systems-level process creation in C, data structures, and foundational web development.

---

## 📂 Project Directory

### 1. Java Object-Oriented Programming & Logic
* **Geometric Objects**
  * Implements core object-oriented principles including encapsulation, inheritance, and method overriding.
  * Calculates geometric properties such as area and perimeter across various shape classes.
* **Compute Tax Program**
  * A Java application utilizing conditional logic, arithmetic operations, and user input handling to calculate individual tax brackets.
* **Account Management Program**
  * An OOP-based Java application simulating banking account operations, balancing, and state management.

### 2. Data Structures & Simulations
* **Ant Farm Simulation**
  * An advanced Java-based simulation demonstrating algorithmic thinking and object-oriented design.
  * Focuses on state management, entity interaction rules, and structured program execution flow.

### 3. Systems Programming (C)
* **Fibonacci Sequence Process Generator**
  * A systems-level C program utilizing parent-child process creation (`fork()`) to generate the Fibonacci sequence concurrently across processes.

### 4. Early Web Development (HTML / CSS)
* **Rachel Portfolio (HTML Website)**
  * One of my foundational web design projects built using raw HTML and CSS.
  * Highlights early responsive styling, structural layout building, and markup fundamentals.
